\# Классификация и кластеризация данных DASS-42



В работе рассматривается самостоятельно выбранная прикладная задача анализа данных DASS-42, связанных с оценкой уровней депрессии, тревожности и стресса.



Цель работы — доработать модель машинного обучения до многоклассовой классификации и сравнить результат с кластеризацией без использования целевой метки.



В первой части реализована многоклассовая классификация. Модель Random Forest Classifier определяет пять классов состояния:



\- норма;

\- лёгкий уровень;

\- умеренный уровень;

\- тяжёлый уровень;

\- крайне тяжёлый уровень.



В результате классификации была получена точность около 90,26%. Также построены график метрик качества, матрица ошибок и график важности признаков.



Во второй части выполнена кластеризация методом K-Means. Для этого из данных удаляется целевая переменная, после чего алгоритм самостоятельно выделяет группы объектов. Полученные кластеры сравниваются с реальными классами.



По результатам кластеризации лучшее число кластеров по silhouette score составило k = 2. Для сравнения с реальными пятью классами также использовалось k = 5. Значение purity составило около 0,7695.
