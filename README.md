# Классификация уровней психологического дистресса и кластеризация данных DASS-42

В работе рассматривается самостоятельно выбранная прикладная задача анализа анкетных данных DASS-42.  
Цель работы — построить модель машинного обучения, способную определять интегральный уровень выраженности психологического состояния по числовым признакам анкеты, а также сравнить результат классификации с кластеризацией без использования целевой метки.

## Описание задачи

В первой части работы реализована задача многоклассовой классификации.  
Модель была доработана таким образом, чтобы определять не два состояния, а пять уровней выраженности психологического дистресса:

- норма;
- лёгкий уровень;
- умеренный уровень;
- тяжёлый уровень;
- крайне тяжёлый уровень.

Для классификации используется модель `Random Forest Classifier`.

Во второй части работы выполнена кластеризация методом `K-Means`.  
Для этого из датасета удаляется целевая переменная, после чего алгоритм самостоятельно выделяет группы объектов. Полученные кластеры сравниваются с реальными классами для оценки того, насколько хорошо алгоритм способен находить внутреннюю структуру данных.

## Используемый датасет

В работе используется датасет DASS-42.  
Каждый объект соответствует одному респонденту, а признаки представлены числовыми значениями, полученными на основе ответов анкеты.

Основные характеристики датасета:

- количество объектов: 39 775;
- количество признаков: 62;
- количество классов: 5;
- тип данных: табличные числовые данные;
- формат данных: CSV.

## Результаты классификации

В результате обучения модели классификации были получены следующие показатели:

- Accuracy: 0.9026;
- Balanced accuracy: 0.7553;
- F1 macro: 0.7618;
- F1 weighted: 0.8999.

Также были построены:

- график метрик качества;
- матрица ошибок;
- график важности признаков.

Результаты сохраняются в папке:

```text
1 классификация/figures
```

## Результаты кластеризации

Для кластеризации использовался алгоритм `K-Means`.

По метрике `silhouette score` лучшее количество кластеров составило:

```text
k = 2
```

Для сравнения с реальными пятью классами дополнительно использовалась кластеризация при `k = 5`.

Основные результаты сравнения кластеров с реальными классами:

- Purity: 0.7695;
- Adjusted Rand Index: 0.1555;
- Normalized Mutual Information: 0.4049.

Результаты сохраняются в папке:

```text
2 кластеризация/figures
```

## Вывод

В ходе работы была доработана модель машинного обучения для решения задачи многоклассовой классификации. Модель определяет пять уровней выраженности психологического состояния и показывает точность около 90%.

Кластеризация методом K-Means позволила выявить внутреннюю структуру данных без использования целевой переменной. Полученные кластеры частично совпали с реальными классами, что подтверждает наличие групп в данных, однако классификация показала более точный результат.
