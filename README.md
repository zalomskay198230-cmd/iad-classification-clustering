#### Лабораторная работа по ИАД

В проекте выполнены два задания:

1. Многоклассовая классификация по датасету DASS-42.
2. Кластеризация методом K-Means без использования меток классов.

#### Установка зависимостей

```bash
pip install -r requirements.txt
```

#### Запуск задания 1 - классификация

```bash
python "1 классификация/ml.py"
```

После запуска результаты сохраняются в папке:

```text
1 классификация/figures
```

#### Запуск задания 2 - кластеризация

```bash
python "2 кластеризация/clustering.py"
```

После запуска результаты сохраняются в папке:

```text
2 кластеризация/figures
```

#### Отчетные материалы

Основные документы находятся в папке:

```text
reports
```

Файл "Недореферат.docx" также помещен в папку "2 кластеризация", так как по заданию он относится ко второй части.

#### Основные результаты

* Accuracy классификации: 0,9026.
* Лучшее k по silhouette: 2.
* Purity при сравнении кластеров с реальными классами: 0,7695.
